# 公共渠道经营台

入口：`/channel-entry?year=2026&month=9`。此入口不要求登录，持有链接的人可以查看所有渠道并填写数据。填写人是自报姓名，不代表认证身份。原后台 `/channel-data` 及其 API 仍要求登录，未改动。

## 使用

- 共用一个年月筛选，上方经营看板、下方负责人填报。
- 周选择只保留顶部「统计范围」一处，联动 KPI、板块、排行、ROI 与周环比。全月模式的周环比自动选最新已录入周。周标签显示日期，遵循原导入规则：周一至周日，按周日归属月份；例如 2026 年 9 月 W1 为 8/31–9/6，只有四个统计周。填报表和趋势图展示实际 4/5 周，不改变数据库五周结构；非日历周存在历史非零值时仍展示「日期待核对」，保留金额但不编造环比。切换范围不丢草稿，切换月份恢复全月。
- 浏览器进入月份时调用 `POST /api/channel-entry/prepare` 补齐有效渠道的 W1–W5 空白行；GET 数据接口只读。
- 生成时通过原数据库唯一键及 `createMany(skipDuplicates)` 去重，不覆盖现有行、金额、评级或预算。补救按钮重新执行同一幂等操作。
- 渠道可通过 `Channel.entryDisabledFromMonth` 设置停止填报的首月（YYYYMM，例如 202609）。公共经营台从该月起不显示该渠道，也不再为其生成空行或接受保存；更早月份的历史查询、统计和原始记录保持不变。此字段默认为空，不改变其他渠道；清空即可恢复。它只影响公共填报流程，不删除渠道、金额、审计，亦不改写原后台及飞书备用数据。
- 新月份继承渠道最近历史币种和负责人，不复制金额；核算汇率按下述规则确定。
- 新月份保持历史币种/负责人，但不再无条件沿用历史汇率：已有本月记录或统一的本月核算率优先保留；首次创建的外币月份优先获取 ECB 最新可用参考价（补录历史月使用月末历史参考），失败才沿用旧值并明确提示。已有记录不自动重算。
- 顶部汇率栏分开显示「本月核算汇率」和「最新参考价/数据日期」。参考价通过 Frankfurter v2 的 ECB 固定来源查询，服务端缓存 1 小时，页面打开时每小时及重新可见时检查，可手动刷新（最短 1 分钟重查）；接口失败、过期数据明确标注，不把旧值伪装为当天报价，也不修改订单共用汇率表。这是工作日参考价，不是盘中实时行情。
- 「应用本月」只允许当前月份，且需先保存或撤销草稿、填写操作人并确认。可用参考价或手动输入核算率；按币种重算全部有效渠道 W1–W5 的 CNY 销售/广告/退款，使用十进制四舍五入到分。原币金额、填写标记、人民币成本/预算、负责人、备注、历史和未来月份、停填渠道均不改动。事务中校验所有渠道版本，冲突时整批拒绝；每行写入汇率修改审计，记录调整前后的汇率和人民币金额。查看参考价永远不重算报表。
- 各行原币录入，汇总按每条周记录的 CNY 本位币值；ROI 用汇总销售额除以汇总广告费，不取各渠道比例平均。
- 顶部 KPI 显示上月变化率。未结束月份的全月模式自动按已录入进度对齐上月，例如本月累计至 W3 比较上月 W1–W3；历史已结束月份保持全月对全月。单周 Wn 对比上月同一 Wn，不是周环比。不存在对应周、日期待核对、缺数据或上期为 0 显示「—」。变化率 = (本期 − 上期) ÷ |上期|，广告占销也是相对变化率而非百分点差。采用各月核算汇率；渠道覆盖和缺报仍可能不同，提示不宣称同渠道可比。
- 看板优先展示「渠道 ROI 对比」，替代整体 ROI 卡片与填报完成度/涨跌数量条。支持全月或 W1–W5、板块筛选、指定多个渠道对比、ROI 升降序，销售额/广告费/广告占销同列展示，点击渠道定位填报行。
- 选择单周时，同一张 ROI 表增加本周/上周 ROI、变化值与变化率，保留本周销售额、广告费和广告占销；支持涨幅/跌幅优先排序。W1 使用上个月实际最后一个日历周（W4 或 W5，含跨年），按渠道 ID 匹配，缺数据不回退更早的非空周。变化率为差值 ÷ |上周 ROI|；上周 ROI 为 0 时变化值仍可用，但变化率显示「—」。全月模式不显示周环比列，单周的涨跌排序在全月模式自动使用 ROI 高低排序。
- 渠道 ROI 按该渠道选中周期的销售总额 ÷ 广告总额计算，不平均周 ROI；单边缺失数据不计算，完全空白周不当作 0，已确认广告为 0 的渠道显示「无广告投入」且不参与 ROI 排名。全月对比展示已录入周范围，避免把不同填报范围误认为完整月份；对齐周范围和渠道归因口径后比较。
- 空白不等于零。新记录的填写标记为 false；填写 0 后标记为 true。历史记录标记为空，历史非零视为已填，历史零值按未确认展示为空，不改写原金额。
- 单行保存 / 保存全部改动；版本冲突返回 409，避免覆盖他人修改。草稿按月份保留在本机浏览器 7 天，不自动提交，不跨设备；网站内切换月份/刷新自动保留和恢复。重新打开页面时提示恢复/下载/丢弃，不混用另一浏览器窗口的草稿。备份不可用时显示提示，并在离开前警告。
- 恢复草稿或收到保存冲突后，按字段核对旧值、自己的输入和服务器最新值；互不重叠的编辑合并，同一位置双方都修改时要求选择保留自己的值或服务器值，再手动保存。未解决冲突可继续备份，刷新不能绕过核对。停填渠道的草稿保留并提供下载，不删除历史数据。
- 填写人姓名独立于渠道负责人，保存时必填；缺失时定位到姓名输入框，显示红框/红字（不叠加 toast），本机记住姓名。修改过的单元格显示橙框，保存栏在桌面端滚动时固定；空白行显示「未填写」，不再把自动生成的空行误标为已填报。
- 支持只看未保存、筛选外未保存行计数、撤销本行修改（需确认）。保存全部包含被筛选隐藏的改动；保存期间锁定编辑与重复提交，显示批量进度，只提示一次结果。失败原因保留在对应行，成功行立即更新看板，失败行和未处理行保留草稿。冲突不自动覆盖。导出前有未保存改动时明确提示仅导出已保存数据。
- 周环比为选中 Wn 对比实际上一周；W1 对比上个月最后一个日历周，1 月跨年。缺失数据不算下降；上周为 0 时变化率不可用。
- 保存与审计在同一事务中写入。修改记录公开显示姓名、时间、渠道和前后值，不暴露 IP 和 User-Agent。
- 支持当前月份的 CSV 导出，文本做表格公式注入防护。

## 数据源

`ChannelMetricPeriod` 是网站的主数据，`ChannelEntryAudit` 保存操作记录。新增的两个 nullable 填写标记不影响旧字段。该页面不调用飞书，也不要求去飞书生成月份或同步。

旧后台飞书同步保留作为备用入口；手动执行旧同步会按飞书值覆盖对应周报，请勿与网站填报混用。用户认证、专属链接、审批和月份锁定不在本次内部试用版本范围内。无登录意味着链接泄露者同样可访问；noindex 仅减少索引，不提供访问控制。

## 接口

- `GET /api/channel-entry?year=&month=` 当前月及上月可比数据。
- `POST /api/channel-entry/prepare` 幂等补齐当月行。
- `PATCH /api/channel-entry/rows/:channelId` 提交姓名、owner、remark、version、5 周 number/null 输入。
- `GET /api/channel-entry/audits?year=&month=` 最近 100 次保存。
- `GET /api/channel-entry/exchange-rate?currency=USD&refresh=1` 查询参考价、实际数据日和服务器当前月份（只读）。
- `POST /api/channel-entry/exchange-rate` 经姓名/月份/币种/汇率/全量版本校验后，事务重算当月该币种的有效渠道。
